# Institution logos

Each file is the official logo published by the institution on its own website.
`SOURCES.json` records the exact source URL and retrieval date for every file.

These marks are the trademarks of their respective institutions. They are included
**only to identify the institution alongside its catalog entries** (nominative use)
and are not covered by this repository's MIT licence. Inclusion is not affiliation
or endorsement. Any institution that would rather not appear here can open an issue
and the file will be removed; the site falls back to a lettermark automatically.

Regenerate with `python scripts/fetch_logos.py`.
